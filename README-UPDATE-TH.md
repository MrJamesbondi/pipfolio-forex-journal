# วิธีอัปเดต Pipfolio Forex Journal

แพ็กนี้เพิ่มเครื่องคำนวณขนาดล็อตตามเงินเสี่ยง แก้การคำนวณกำไร/ขาดทุนของ XAUUSD และคู่หลัก EURUSD, GBPUSD, AUDUSD, NZDUSD เพิ่มสถิติแยกคู่ และทำให้เมนู ตัวกรอง การแก้รายการ และการใช้บนมือถือทำงานได้

## ก่อนอัปเดต

1. เปิดเว็บปัจจุบัน แล้วกด **Download backup** ด้านล่าง เก็บไฟล์สำรองไว้
2. คลิกขวาไฟล์ ZIP นี้ แล้วเลือก **Extract All…**
3. XAUUSD ตั้งขนาดสัญญาเริ่มต้นเป็น 100 ออนซ์ต่อ 1 lot แต่แต่ละโบรกเกอร์อาจกำหนดต่างกัน ตรวจสอบสเปกในโบรกเกอร์ และแก้ค่าในแบบฟอร์มได้
4. ไม่ต้องลบหรือแก้ Supabase, Environment Variables, `node_modules` หรือ `.next`

## อัปเดตผ่านหน้า GitHub

1. เข้า GitHub repository ที่เชื่อมกับ Vercel โปรเจกต์ `pipfolio-forex-journal`
2. กด **Add file → Upload files**
3. เปิดโฟลเดอร์ที่แตก ZIP แล้วลากไฟล์และโฟลเดอร์ด้านใน เช่น `app`, `lib`, `supabase`, `package.json` ขึ้นหน้า GitHub (ลากไฟล์ข้างใน ไม่ใช่ไฟล์ ZIP)
4. ถ้ามีถามให้แทนที่ไฟล์เดิม ให้ยืนยันการแทนที่ไฟล์โค้ด
5. กด **Commit changes** ด้านล่าง
6. เข้า Vercel → โปรเจกต์ → **Deployments** แล้วรอ deployment ใหม่ขึ้น **Ready** และ **Production**
7. กด **Visit** จาก deployment ใหม่นั้น แล้วรีเฟรชเว็บด้วย `Ctrl + Shift + R`

## หลังอัปเดต

- เข้าสู่ระบบด้วยบัญชี Supabase เดิม ไม่ต้องสมัครบัญชีใหม่
- คู่ที่รองรับการคำนวณล็อตและกำไร/ขาดทุนแบบ USD คือ EURUSD, GBPUSD, AUDUSD, NZDUSD และ XAUUSD
- คู่ FX ใช้สัญญามาตรฐาน 100,000 หน่วยต่อ lot; XAUUSD เริ่มที่ 100 ออนซ์ต่อ lot และปรับได้ตามโบรกเกอร์
- แนะนำขนาดล็อตคำนวณจากยอดบัญชี × ความเสี่ยง % ÷ เงินที่เสี่ยงได้ที่ 1 lot และปัดลงทีละ 0.01 lot; ไม่รวม spread, commission, swap หรือ slippage ในความเสี่ยงตาม Stop Loss
- การเปลี่ยนสูตรจะคำนวณใหม่ให้รายการเก่าของคู่ที่รองรับเมื่อเปิดเว็บ รายการเทรดตัวอย่างเก่าจะถูกปรับให้ใช้คู่ที่รองรับ รายการจริงยังคงอยู่
- ถ้า Vercel ขึ้น **Build Failed** อย่าแก้ค่าคีย์หรือสร้างบัญชีใหม่ ให้ส่งภาพข้อความผิดพลาด โดยปิดบังค่า Key และรหัสผ่าน

อย่าส่ง Publishable key, Secret key หรือรหัสผ่านให้ใคร
