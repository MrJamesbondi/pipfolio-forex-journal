# Pipfolio — Forex Trading Journal

Trading Journal สำหรับ Forex มีระบบบัญชีและซิงก์ข้อมูลส่วนตัวข้ามอุปกรณ์ด้วย Supabase เมื่อทำตามหัวข้อ “เปิดใช้การซิงก์” เสร็จ เว็บที่เผยแพร่บน Vercel จะใช้บัญชีเดียวกันเพื่อเปิดดูรายการเทรดจากมือถือหรือคอมพิวเตอร์เครื่องอื่นได้

## เปิดใช้การซิงก์ (ทำครั้งเดียว)

### 1. สร้างฐานข้อมูล Supabase

1. สมัคร/เข้าสู่ระบบที่ [supabase.com](https://supabase.com) แล้วกด **New project**
2. ตั้งชื่อโปรเจกต์และรหัสผ่านฐานข้อมูล เก็บรหัสผ่านไว้เป็นส่วนตัว แล้วรอให้โปรเจกต์สร้างเสร็จ
3. เปิด **SQL Editor → New query**
4. เปิดไฟล์ `supabase/schema.sql` ในโฟลเดอร์โปรเจกต์ คัดลอกทั้งหมดไปวางใน SQL Editor แล้วกด **Run**
5. ไปที่ **Project Settings → API Keys** แล้วคัดลอก **Project URL** และ **Publishable key** (บางหน้าจออาจเรียก `anon` หรือ `public` key)

ตารางเปิดใช้ Row Level Security (RLS) และมีนโยบายให้ผู้ใช้ที่ล็อกอินอ่าน/เขียนได้เฉพาะแถวที่เป็นของบัญชีตัวเอง ห้ามนำ `service_role` หรือ Secret key มาใส่ในเว็บ

### 2. เผยแพร่เว็บบน Vercel

ทำขั้นตอน GitHub และ Vercel ตามหัวข้อถัดไปก่อน เมื่อ Vercel สร้างโปรเจกต์แล้ว:

1. ใน Vercel เปิดโปรเจกต์ → **Settings → Environment Variables**
2. เพิ่มตัวแปรต่อไปนี้ทั้งสองตัวสำหรับ **Production** (และ Preview ถ้าต้องการ):
   - `NEXT_PUBLIC_SUPABASE_URL` = Project URL จาก Supabase
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` = Publishable key จาก Supabase
3. กด Save แล้วไปที่ **Deployments** เลือก **Redeploy** เวอร์ชันล่าสุด เพื่อให้เว็บอ่านค่าที่เพิ่ม

### 3. ตั้ง URL สำหรับยืนยันอีเมล

1. คัดลอก URL เว็บ Vercel ของคุณ เช่น `https://ชื่อโปรเจกต์.vercel.app`
2. ใน Supabase ไปที่ **Authentication → URL Configuration**
3. ตั้ง **Site URL** เป็น URL เว็บ Vercel
4. เพิ่ม `http://localhost:3000/**` ใน **Redirect URLs** เผื่อทดสอบในเครื่อง (ถ้าไม่ทดสอบในเครื่อง ข้ามได้)

### 4. สมัครและซิงก์

1. เปิดเว็บ Vercel แล้วกด **Sign in to sync**
2. เลือก **สมัครที่นี่** ใส่อีเมลและรหัสผ่าน
3. ถ้าระบบส่งอีเมลยืนยัน ให้กดลิงก์ในอีเมล แล้วกลับมาที่เว็บเพื่อ Sign in
4. ระบบจะย้ายรายการในเบราว์เซอร์นี้ขึ้นบัญชีของคุณเมื่อ Cloud ยังไม่มีข้อมูล จากนั้นรายการที่เพิ่มหรือลบจะบันทึกบน Cloud
5. เปิด URL เดิมจากอุปกรณ์อื่นแล้ว Sign in ด้วยอีเมลและรหัสผ่านเดิม

ถ้าเคยบันทึกข้อมูลไว้บนเว็บเวอร์ชันเดิม ให้เปิดเว็บเดิมแล้วกด **Download backup** เก็บไฟล์ JSON ไว้ จากนั้นเมื่อเปิดเว็บ Vercel และเข้าสู่ระบบแล้ว กด **Import** เพื่อย้ายข้อมูลเก่า ไฟล์สำรองยังเป็นวิธีเก็บสำเนาเพิ่มที่แนะนำ

## เผยแพร่ผ่าน GitHub และ Vercel

1. สมัคร/เข้าสู่ระบบ [GitHub](https://github.com) แล้วสร้าง repository ใหม่
2. แตกไฟล์ ZIP ของโปรเจกต์ แล้วอัปโหลดไฟล์และโฟลเดอร์ข้างในขึ้น repository (ไม่ต้องอัปโหลด `node_modules` หรือ `.next`)
3. เข้า [vercel.com](https://vercel.com) เลือก **Add New → Project** เชื่อม GitHub และเลือก repository นี้
4. กด **Deploy** ด้วยค่าที่ Vercel ตรวจจับสำหรับ Next.js แล้วทำหัวข้อ “เปิดใช้การซิงก์” ข้อ 2–4

## ใช้หรือทดสอบในเครื่อง (ไม่บังคับ)

ติดตั้ง Node.js รุ่น LTS แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์ จากนั้นรัน:

```sh
npm install
npm run dev
```

เปิด `http://localhost:3000`. รัน `npm test` เพื่อทดสอบ หรือ `npm run build` เพื่อสร้างเวอร์ชันเผยแพร่

## ข้อมูลและความเป็นส่วนตัว

- ถ้ายังไม่ตั้ง Supabase และไม่ได้เข้าสู่ระบบ เว็บเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเหมือนเดิม
- หลังตั้งค่าและเข้าสู่ระบบ ข้อมูลเทรดจะเก็บในฐานข้อมูล Supabase และเรียกดูข้ามอุปกรณ์ได้
- ผู้ใช้แต่ละบัญชีเห็นได้เฉพาะรายการของตัวเอง ไม่มีแผงแอดมินที่มองเห็นข้อมูลทุกบัญชี
- อย่าแชร์รหัสผ่านหรือคีย์ลับ และเก็บไฟล์ JSON backup ในที่ปลอดภัย
- แพ็กเกจนี้ยังไม่ได้เชื่อมกับบัญชี Supabase/Vercel ของคุณและยังไม่ได้เผยแพร่ ต้องทำการตั้งค่าข้างต้นเพื่อเปิดใช้งานจริง
